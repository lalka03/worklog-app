# Учёт работы (Worklog)

## Пилот Worklog Yandex Test

Пилотная ветка — `worklog-yandex-test`. Android-пакет `com.worklog.app.yandex.test` устанавливается рядом со сборкой #28 и рабочим приложением. На телефоне он отображается как **Worklog Yandex Test**. До завершения приёмки используйте вымышленные учётные записи и записи о сменах.

Для первой регистрации нужны адрес электронной почты, пароль и одноразовое приглашение от администратора. Для повторного входа достаточно адреса и пароля. Сотрудник ведёт собственный учёт. Администратор ведёт свой учёт и может просматривать записи сотрудников во вкладке «Сотрудники».

## Локальные проверки

Запустите из корня проекта с Python 3.12 и Node.js 20.

```bash
python -m pip install -r backend/requirements.txt
python -m unittest discover -s backend/tests -v
npm test
```

Для локальных проверок адрес шлюза не требуется. Интеграционные тесты YDB запускаются при наличии настроенной изолированной тестовой базы.

## Получение пилотного APK

1. После согласования развёртывания оператор проверяет HTTPS-шлюз и указывает его публичный адрес в переменной репозитория GitHub Actions `WORKLOG_API_BASE_URL`. Укажите только `https://` и имя хоста. Процедура проверок описана в [инструкции для оператора](cloud/README.md).
2. В GitHub Actions вручную запустите `.github/workflows/build-apk.yml` для ветки `worklog-yandex-test`. Обычный push в эту ветку запускает тесты. Для подписанной сборки нужен ручной запуск этой ветки и успешно пройденные тесты.
3. Скачайте артефакт **WorklogYandexTest-release** и извлеките `app-release.apk`. Установите проверенный оператором APK на телефон и убедитесь, что обе сборки открываются независимо. Пилот распространяется напрямую для тестирования.

## Обновление сборки #32 и проверка офлайн-режима

Приёмка на телефоне ещё не завершена. Используйте выделенную тестовую учётную запись и вымышленную смену.

1. Дождитесь, пока оператор обновит совместимый с #32 пилотный API и сохранит предыдущую версию Cloud Function для отката. Инструкция для оператора приведена в [cloud/README.md](cloud/README.md).
2. Установите новый APK поверх #32. У обновления должны быть тот же пакет `com.worklog.app.yandex.test`, тот же сертификат подписи и больший код версии. Не удаляйте приложение и не очищайте его данные.
3. С доступом к интернету откройте обновлённое приложение и дождитесь загрузки личного журнала. Успешное обновление сохранённого сеанса #32 создаёт разрешение для офлайн-входа. Если сохранённого сеанса нет или срок его действия истёк, войдите с флажком «Запомнить меня на 30 дней».
4. Включите авиарежим и убедитесь, что Wi-Fi тоже выключен. Полностью закройте приложение и откройте его заново. Проверьте, что доступны ранее загруженный личный журнал, настройки и итоги. Создайте тестовую смену, измените её и сохраните. Для администратора вкладка «Сотрудники» в этом режиме недоступна.
5. Выключите авиарежим. Дождитесь проверки сеанса и синхронизации. Убедитесь, что сохранённая правка появилась в личном журнале при независимой проверке онлайн. Удалите только тестовую смену и так же проверьте, что удаление синхронизировалось.

Офлайн-доступ действует не более 30 дней с исходного входа с запоминанием. Обновление сеанса этот срок не продлевает. Приложение узнаёт об отзыве сеанса сервером только при восстановлении связи и проверяет сеанс перед отправкой изменений. Без связи проверка срока зависит от часов телефона. Перевод часов назад за последнюю сохранённую отметку блокирует офлайн-вход, а перевод вперёд может закрыть доступ раньше.

Кнопка «Выйти» сразу закрывает личный журнал и удаляет сохранённое разрешение на этом телефоне. Если защищённое хранилище вернёт ошибку, приложение предложит повторить выход. Для входа после выхода нужен интернет. Для отзыва сеанса на сервере выход выполняйте при доступном API.

## Ручной экспорт и импорт

В исходном приложении сохраните файл `.json` через «Настройки → Экспорт резервной копии». Войдите в нужную пилотную учётную запись и выберите «Настройки → Импорт из файла». Для приёмки используйте тестовый файл. Перенос рабочих данных возможен после согласования пилота.

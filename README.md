# Учёт работы (Worklog)

Приложение для учёта рабочих смен и расчёта заработка. Сделано как веб-приложение в папке `www`, оборачивается в Android APK через Capacitor + GitHub Actions.

## Как получить APK с телефона

1. Загрузи все файлы из этой папки в свой репозиторий `lalka03/worklog-app` на GitHub.
2. Открой вкладку **Actions** в репозитории.
3. Найди workflow **Build Android APK** → нажми **Run workflow**.
4. Когда сборка закончится (зелёная галочка), открой её и скачай артефакт **worklog-debug-apk**.
5. Установи APK на телефон (понадобится разрешить установку из неизвестных источников).

## Импорт старых данных

Данные из старой версии экспортируй как `.json` (Настройки → Экспорт резервной копии). В новом приложении: Настройки → Импорт из файла.

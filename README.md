# Учёт работы (Worklog)

## Тестовая ветка: многопользовательский режим Worklog Test

- Android-пакет `com.worklog.app.test`: устанавливается рядом с рабочим Worklog, не заменяет его.
- Firebase-проект `worklog-test-3d6d7`: только тестовые данные. Рабочую базу не копируем.
- Вход/самостоятельная регистрация и восстановление пароля — через Firebase Authentication.
- Записи и локальный кэш разделены по UID. Сотрудник видит только свои данные. Администратор ведёт собственный учёт как обычный пользователь, а во вкладке «Сотрудники» просматривает календарь, детали смен и итоги других пользователей без редактирования. Роли назначаются администратором проекта вручную (узел `admins/<UID>` со значением `true`), приложение не может менять роли.
- Перед использованием этой версии опубликовать обновлённый `database.rules.json` **только** в тестовом проекте: владелец UID может записывать свои данные независимо от роли; остальные записи доступны администратору только для чтения.
- Запустить `npm test`. После push в `worklog-multiuser-test` GitHub Actions собирает подписанный APK в артефакт `WorklogTest-release`.
- Проверка на телефоне: регистрация двух сотрудников, разные записи, выход и повторный вход, затем проверка административного просмотра. Не импортировать реальные рабочие данные в тестовую базу.
- Не сливать эту ветку в `main` без отдельной проверки миграции рабочих данных и замены тестовой конфигурации.

Приложение для учёта рабочих смен и расчёта заработка. Сделано как веб-приложение в папке `www`, оборачивается в Android APK через Capacitor + GitHub Actions.

## Как получить APK с телефона

1. Загрузи все файлы из этой папки в свой репозиторий `lalka03/worklog-app` на GitHub.
2. Открой вкладку **Actions** в репозитории.
3. Найди workflow **Build Android APK** → нажми **Run workflow**.
4. Когда сборка закончится (зелёная галочка), открой её и скачай артефакт **WorklogTest-release**.
5. Установи APK на телефон (понадобится разрешить установку из неизвестных источников).

## Импорт старых данных

Данные из старой версии экспортируй как `.json` (Настройки → Экспорт резервной копии). В новом приложении: Настройки → Импорт из файла.

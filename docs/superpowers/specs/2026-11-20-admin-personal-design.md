# Worklog Test: личный кабинет администратора

Администратор — обычный пользователь со своим календарём, итогами и настройками, дополнительно имеет отдельную вкладку «Сотрудники». Выбрана отдельная вкладка вместо ссылки в настройках, поскольку просмотр сотрудников должен быть быстрым. Сотрудники без административной роли видят прежние три вкладки. Чужие данные отображаются только для чтения: выбор сотрудника, календарь, детали дня и итоги с его тарифами. Собственные записи синхронизируются по собственному UID, не смешиваясь с чужими. Firebase разрешает запись только владельцу UID, роли остаются недоступными для клиентской записи. Только тестовая ветка и тестовый Firebase; основной проект, данные и идентификатор APK не меняются.
